Créez vos packages Chocolatey depuis des installateurs MSI et EXE.

Chocolatey Packager est un générateur graphique de packages Chocolatey pour Windows. Sélectionnez un installateur, vérifiez les informations et les paramètres silencieux, puis générez un fichier .nupkg à stocker sur votre poste ou votre dépôt réseau.

Comment créer un package Chocolatey à partir d'un EXE ou d'un MSI ?

  1. Téléchargez le ZIP du dépôt et décompressez tous les fichiers sous Windows.
  2. Ouvrez Start.cmd et sélectionnez votre installateur .exe ou .msi.
  3. Vérifiez le nom, la version, l'éditeur et les paramètres d'installation silencieuse.
  4. Choisissez le dossier de destination puis générez le package .nupkg.
  5. Testez une installation réelle sur une VM Windows avant tout déploiement.

Questions fréquentes

Faut-il installer Chocolatey pour fabriquer un package ?

Non. L'outil utilise Windows PowerShell 5.1 sur le poste de création. Chocolatey doit être présent sur les postes qui installeront le package.

Peut-on convertir n'importe quel EXE en installation silencieuse ?

Non. Les arguments suggérés ne sont pas garantis. Consultez la documentation de l'éditeur et testez les paramètres sur une VM.

Un package valide est-il prêt à déployer ?

Pas forcément. Le validateur vérifie la structure et l'intégrité du package, mais pas la réussite d'une installation, d'une mise à jour ou d'une désinstallation.

Peut-on créer un dépôt de logiciels interne ?

Oui, les fichiers peuvent être exportés sur un disque local ou un partage réseau, dans le respect des droits de redistribution des logiciels.

Chocolatey Packager est un projet communautaire indépendant, non affilié à Chocolatey Software. Vérifiez les droits de redistribution des installateurs tiers.
