How to create a Chocolatey package

  1. Download the repository ZIP and extract all its files on Windows.
  2. Launch Start.cmd and select an .exe or .msi installer.
  3. Review the package name, version, publisher and silent installation switches.
  4. Select an output directory and create the .nupkg file.
  5. Validate an installation on a disposable Windows VM before deploying.

Frequently asked questions

Does Chocolatey Packager need Chocolatey installed?

No, it creates packages with Windows PowerShell 5.1. To install a generated package on a target computer, you need Chocolatey there.

Can I turn any EXE installer into a silent Chocolatey package?

Not automatically. Silent switch detection is a suggestion, not a guarantee. Check vendor documentation and test on a VM.

Does package validation mean the application installs correctly?

No. The validator checks structure and integrity, not the real installation, upgrade or uninstall process.

Can I create packages for a local software repository?

Yes. You can export packages to a local directory or network share, subject to software redistribution permissions.

Chocolatey Packager is an independent community project, not affiliated with Chocolatey Software. Check third-party redistribution rights.
